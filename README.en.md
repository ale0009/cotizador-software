# How much does your software cost?

[Español](README.md)

A single-purpose tool: build your project from pieces (login, payments, admin panel, mobile app, API, reports…), pick your team with monthly salaries in Colombian pesos, and see the price and schedule **range** (P50, P80, P90) live, computed with a Monte Carlo simulation.

- `/`: the tool. It opens with a clearly marked example (a small online store).
- `/proceso/`: how it was made (in Spanish): sources, method, charts, design decisions and limitations.

> This is not a formal quote. Every value (minimum wage, transport allowance, 52 % payroll load factor, salaries, hours per piece, exchange rate) is a reference value, editable, and must be verified.

## How to use it

1. Toggle the pieces your software needs. "Ajustar horas" lets you edit the optimistic, most likely and pessimistic hours.
2. Choose how many people per role and their monthly salary. The hourly cost includes Colombian payroll benefits (52 %) and the transport allowance when the salary is below 2 minimum wages.
3. Read the range: P80 price as the headline, P50–P90 range, weeks, probability of staying within the budget plus contingency, histogram and breakdown.
4. Switch currency (COP/USD) and the exchange rate in the header; other assumptions live in "Supuestos y parámetros".

Serve the folder with any static server (e.g. `python3 -m http.server`). No build step: HTML, CSS and JS modules, ready for GitHub Pages.

## How it works

- `js/nomina.js`: company hourly cost `(salary × 1.52 + allowance if applicable) / 160`.
- `js/riesgo.js` + `js/azar.js`: Beta-PERT Monte Carlo (5000 iterations, seed 42). `azar.js` ports Python's Mersenne Twister and `betavariate` so results match the original engine exactly.
- `js/cascada.js`: labour, contingency, non-labour costs, commercial margin, price tiers, capacity and currency conversion.
- `js/modelo.js`: `cotizar()` ties everything together. Price per percentile = simulated cost × (1 + margin).

## Tests

```bash
node --test
```

Tests compare the JavaScript engine against values computed by running the original Python code (`test/referencias.json`, generated by `scripts/generar_referencias.py`, which needs the private eiran repository).

## Where it comes from

- [optimizacion-presupuesto-ecommerce](https://github.com/ale0009/optimizacion-presupuesto-ecommerce): an operations research project (mixed-integer programming with PuLP) done at Universidad ECCI. Source of the hourly-cost formula, reference salaries and the most likely hours of seven pieces.
- eiran: Mario's own project-feasibility assistant. `costo_laboral.py`, `riesgo.py` and `cascade_engine.py` were ported from its budget module.
